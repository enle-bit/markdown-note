> 学习时间：2026年10月

> 学习掌握基本常用语法

## 1.标题

用`#`表示标题层级，与文字间要加空格

## 2.段落与换行

段落间用一个空行隔开，行内换行在末尾加两个空格加回车键

## 3.强调

- **加粗**
  
- *斜体*
  
- ***加粗斜体***
  
- ~~删除线~~
  

## 4.列表

### 无序列表

- 阿吧
  
- 咕咕
  
- 嘎嘎
  

### 有序列表

1. 第一步
  
2. 第二步
  
3. 第三步

## 7.代码

反引号包裹，`print("Hello")`

三个反引号包裹可以指定语言：

```python
print("Hello,Markdown！")
```

## 8.表格

```markdown
|语法|作用|
|---|---|
|`#`|标题|
|`##`|加粗|
|`-`|无序标题|
|`>`|引用|
```
